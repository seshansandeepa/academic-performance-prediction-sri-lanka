# Results

This folder contains the final aggregated outputs generated from the research analysis.

The results include:

- participant screening summaries
- sample characteristics
- target-class distribution
- baseline model performance
- tuned model performance
- nested cross-validation results
- class-wise recall
- model stability analysis
- statistical comparison
- confusion matrices
- feature importance
- permutation importance
- final publication figures and tables

The raw participant-level survey dataset is not included in this repository in order to protect participant privacy.

The final results are organized into:

- `figures/` — publication-ready visualizations
- `tables/` — aggregated research result tables
